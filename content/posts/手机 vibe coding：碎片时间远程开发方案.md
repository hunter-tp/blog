# 手机 vibe coding：碎片时间远程开发方案

## 背景

AI 完成一个任务通常需要好几分钟，复杂的任务甚至需要几十分钟。在 AI 执行期间，你不需要守着电脑，只需要在任务完成后查看结果、做下一步决策。这个特性非常适合利用碎片化时间——用手机远程接管电脑，随时跟进。

典型的场景：

1. 上下班地铁上
2. 等人的时候
3. 带娃（主打陪伴）
4. ...

## 方案一：远程软件

只要是支持跨平台的远程软件都可以，我使用的是网易的 UU 远程。

**优点：**
- 图形化。电脑能做的事情，基本都能在手机上操作。对于 vibe coding 场景，开一个终端就能干活。如果看不清可以放大缩小屏幕。
**缺点：**
- 图形化。是的，图形化即是优点也是缺点。缺点在于图形化很吃网络，如果在弱网环境，卡的啥也干不了。

## 方案二：vpn+ssh+tmux

我的设备是 Mac + iPhone，具体方案是：Tailscale + Termius。

### 安装流程

1. Mac、iPhone 安装 Tailscale、Termius，个人用户均免费
2. Mac 开启远程登录：设置 - 通用 - 共享 - 远程登录。如果需要访问受保护目录（如桌面、文稿），可点击旁边的感叹号开启全盘访问，否则不必开启
3. Mac 安装 tmux：`brew install tmux`

### 具体操作

1. Mac、iPhone 都开启 Tailscale
    - 弱网环境下，Mac 可以安装 mosh 改善连接稳定性。注意需要将 mosh 的路径添加到 `~/.zshenv` 而非 `~/.zshrc`——SSH 登录时不会加载 `zshrc`，写在 `zshenv` 才能保证 mosh 可被找到
2. iPhone 上使用 Termius，连接 Mac 的 SSH。打开 Tailscale 即可看到主机名
    - 弱网环境下，Termius 可开启 mosh 开关。注意 Termius 的 mosh 目前有字符显示问题，如果影响使用可以试试 Blink Shell
3. 第一次连进去，先执行 `tmux`，然后正常 vibe coding
4. 后续重连后执行 `tmux attach`，即可恢复上次会话

**优点：**
- 不依赖太好的网络，日常终端操作随时随地

**缺点：**
- 不适合需要图形化操作的场景
- 无法直接查看终端的历史上下文（tmux 滚动缓冲区可以缓解，但有限）

## 如何选择

- **网络稳定、偶尔需要图形化操作** → 方案一，开箱即用
- **弱网环境、以终端操作为主** → 方案二，稳定性更好

两个方案也可以互补：平时用方案二，遇到需要图形化的情况临时切换方案一。
